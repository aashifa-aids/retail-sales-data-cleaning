# Week 1: Data Gathering, Cleaning, and Preprocessing

## Objective
To collect a publicly available dataset and perform
data cleaning and preprocessing using Python.

## Dataset
Online Retail Dataset from the UCI Machine Learning Repository.

Source:
https://archive.ics.uci.edu/dataset/352/online+retail

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Performed
- Data collection and exploration
- Missing value analysis
- Duplicate record detection
- Outlier investigation
- Data type conversion
- Data cleaning and validation
- Exporting the cleaned dataset to CSV

## Project Deliverables
- Cleaned dataset in CSV format
- Python notebook containing the cleaning process
- PDF report documenting the methodology

## Conclusion
This project demonstrates the importance of data
quality and preprocessing before further data analysis.
